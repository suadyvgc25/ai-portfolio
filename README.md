# AI Portfolio

A collection of AI-powered applications built with Python, Streamlit, and OpenAI APIs.

## Projects

### Daily Meal Planner

An AI-powered meal planning app that generates breakfast, lunch, and dinner from user-provided ingredients. The app includes optional dish image generation, MP3 recipe narration, and downloadable HTML meal plans.

- **Live Demo:** https://mealplan-ai.streamlit.app/
- **Code:** [./meal-plan-ai](https://github.com/suadyvgc25/meal-plan-ai)
- **Tech:** Python, Streamlit, OpenAI, HTML/CSS
- **Focus:** Structured AI output, multimodal generation, responsive UI, portfolio-ready product design
